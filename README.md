# Hey, I'm Fenix 👋

I'm a software engineer who enjoys building backend systems, exploring product ideas, and turning messy problems into simple, reliable solutions.

Most of my experience is around backend engineering, distributed systems, APIs, messaging, cloud infrastructure, and system integration. I usually work close to business-critical systems, especially in fintech, banking, insurance, and SaaS environments.

I like working on things that need to scale, communicate well with other systems, and stay maintainable over time.

---

## What I like building

* Backend services that are simple to understand and reliable in production
* APIs and integrations between complex systems
* Event-driven flows using queues, streams, and messaging patterns
* Cloud-native applications with good observability and deployment practices
* SaaS products, internal tools, automation, and AI-powered features
* Systems designed with clean architecture, clear boundaries, and pragmatic engineering decisions
